# Business Landing Website Example

A fully responsive business landing page built for a Udacity project.
This project demonstrates semantic HTML structure, mobile-first responsive design, and advanced CSS techniques including grid layouts, flexbox, background images, and pure CSS mobile navigation.

## Project Structure

```
project/
|
├── css/
│ ├── global.css
│ ├── nav.css
│ ├── footer.css
│ ├── main.css
│ └── contact.css
|
├── img/
│ └── (icons)
|
├── pages/
│ └── contact.html
|
├── index.html
├── LICENSE
└── README.md
```

## How to Run

Simply open index.html in any modern web browser.
No build tools or server environment required.
